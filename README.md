# FileShare - 简易文件共享服务器

一个基于 Java 的轻量级文件共享服务器，支持通过浏览器上传、下载和删除文件。提供 GUI 和无 GUI 两种运行模式。

## 功能特性

- **文件上传**：通过网页界面上传文件到共享目录
- **文件下载**：浏览并下载共享目录中的文件
- **文件删除**：从网页界面删除不需要的文件
- **双模式运行**：支持 GUI 图形界面和无 GUI 命令行模式

### 运行方式

默认以图形界面的方式运行。

### 访问服务

启动后，在浏览器中访问：

```
http://localhost:8080
```

或在其他设备上访问：

```
http://<你的IP地址>:8080
```

## 配置说明

### 端口配置

默认端口为 `8080`，可在 `FileServer.java` 中修改 `PORT` 常量。

### 共享目录

默认共享目录为项目根目录下的 `share/` 文件夹，可在 `FileInit.java` 中配置。

### 命令行参数

- `--no-gui`：以无 GUI 模式运行

## 注意事项

1. **防火墙设置**：确保防火墙允许 8080 端口的访问
2. **文件安全**：不要上传敏感或机密文件
3. **网络环境**：确保客户端和服务端在同一网络或可互相访问
4. **权限问题**：确保程序对 `share/` 目录有读写权限

## 许可证

本项目仅供学习和个人使用。

## 常见问题

**Q: 为什么无法访问服务器？**  
A: 检查防火墙设置，确认 8080 端口已开放。

**Q: 上传大文件失败？**  
A: 检查磁盘空间和内存限制。

**Q: GUI 模式启动失败？**  
A: 程序会自动降级到无 GUI 模式继续运行。
